# Caravan

<img src="skills/caravan/assets/brand/caravan-logo.png" width="360" alt="Caravan">

**AIと進む、あなたの旅。**

CaravanはAIとの会話を振り返り、自分やほかの人の使い方を知るためのツールです。会話の一部を利用中のAIエージェントが読み、どんな場面で何を任せ、どう進めたかを具体例にまとめます。

結果には、本人が選んだ手順や会話で確認できたその後、本人に聞いてみたい問いを載せます。38観点からの詳しい観察と、4軸で要約した旅人タイプも見られます。旅人タイプは16種類あり、材料不足や中間の場合は判定を保留します。具体例・口調・発見メモはタイプ判定に影響しません。

AIの使い方について話を聞くための試作です。能力・成果・人格を評価したり、人に順位を付けたりするものではありません。

## スキルとしてインストールする

Python 3.10以降と、PC内のファイルを扱えるCodexまたはClaude Codeが必要です。結果は普段のブラウザーで開けます。追加のPythonパッケージや専用のAPIキーは不要ですが、利用するAIエージェントの利用枠・費用はかかります。

インストール中に会話履歴は読みません。診断を始める際に、対象範囲と処理先を説明し、本人の承諾を得てから読みます。

### Codex

Codexに次の文章を送ってください。

```text
$skill-installer で、以下のスキルをインストールしてください。
https://github.com/tenonno/caravan/tree/main/skills/caravan
今回はインストールのみ行い、会話履歴の読取や診断は始めないでください。
外部パッケージや追加ツールはインストールせず、不足があれば知らせてください。
```

インストール後は `$caravan` で呼び出します。一覧に現れない場合はCodexを再起動してください。

### Claude Code

Claude Codeに次の文章を送ってください。

```text
https://github.com/tenonno/caravan の skills/caravan フォルダを取得して、
個人用スキル ~/.claude/skills/caravan/ にインストールしてください。
SKILL.mdだけでなく、scripts・assets・LICENSEを含むフォルダ一式を配置してください。
配置後に ~/.claude/skills/caravan/SKILL.md があることを確認してください。
同名のスキルが既にある場合は上書きせず、状況を知らせてください。
外部パッケージや追加ツールはインストールせず、不足があれば知らせてください。
今回はインストールのみ行い、会話履歴の読取や診断は始めないでください。
```

インストール後は `/caravan` で呼び出します。見つからない場合は新しいClaude Codeセッションを開いてください。

スキルは自動更新されません。更新するときはエージェントに依頼し、既存スキルとの差分を確認してから反映してください。診断結果や評価キャッシュは更新対象に含めません。

## 診断を始める

診断に使う作業フォルダを開き、次の文章を送ってください。Claude Codeでは先頭の `$caravan` を `/caravan` に置き換えます。

```text
$caravan 診断してください。診断自身の会話は除外してください。
最初に3つの分析量の違いを説明して、私に選ばせてください。
履歴を読む前に、対象範囲・処理先・注意事項を説明して、私の承諾を待ってください。
```

結果は作業フォルダの `output/semantic/index.html` に保存されます。再実行すると同じファイルを更新します。

会話を読むのは利用中のAIエージェントです。Pythonスクリプトだけでは診断できず、Web版のチャットだけではPC内の履歴を取得できません。

### 履歴を読ませる前に

**PC内の履歴でも、クラウド型エージェントに読ませると、その処理先に内容が渡ります。** 機密情報・個人情報・認証情報を含む可能性があるため、職場の履歴は所属先で認められた環境と範囲でのみ利用してください。自動マスクは完全ではありません。

注意事項だけ確認したい場合は、エージェントに「インストール済みのcaravanのnoticeを実行して。履歴は読まないで」と依頼できます。

## 読み取れる履歴と分析量

Codex、Claude Code、Antigravity CLIのローカル会話ログに対応しています。診断を実行するエージェントと、読み取る履歴の取得元は別です。複数の対応履歴があれば、条件に合う各エージェントの会話から抜粋を選びます。Antigravity IDE・旧Gemini CLIは対象外です。

対象期間の初期設定は直近90日です。診断前に次の3つから分析量を選びます。

| 分析量 | 会話数の上限 | 会話本文＋実行情報の上限 | 選ぶ目安 |
|---|---:|---:|---|
| 少なめ（light） | 6 | 12,000文字 | 読む量を抑えて傾向を見る |
| 中くらい（standard） | 12 | 24,000文字 | lightより多くの場面を見比べる |
| 多め（deep） | 24 | 48,000文字 | より広い場面を探る。時間と費用が増えやすい |

分析する観点と出力形式は同じで、違うのは読む会話の量です。どのモードも各会話の一部を読み、全履歴は読みません。材料不足なら判断を保留し、会話数を増やしても正確になる保証はありません。表の文字数にAIの指示・出力・推論は含まれず、総トークン数や料金の上限ではありません。

動作確認はWindowsの開発環境で行っています。他のOS・アプリ版・ログ形式での動作は保証していません。対応する保存先や詳しい抽出方法は[使い方](docs/usage.md)、検証した範囲は[検証と限界](docs/validation.md)を参照してください。

## 結果を読む・保存する

結果の冒頭で旅人タイプと4軸の全体像を確認し、その下で具体的な使い方を読めます。条件や手順の組み合わせが分かる例を0〜3件示し、ほかの例や口調、観点ごとの説明は「詳しい観察」にまとめています。例の数を埋めるために一般論を追加したり、AIの完了報告を効果の証明にしたりはしません。

「結果の保存・復元」から、詳しい結果をJSONで保存・復元できます。「結果画面をHTMLで保存」を選ぶと、復元した画面も後からそのまま開けます。詳しくは[保存・復元の手順](docs/usage.md#見た目の更新に備えて本人用データを保存する)を参照してください。

## 結果を見せ合うには

比較用には、本人が内容を確認した `output/semantic/share-profile.json` を渡します。結果画面では最大3人分を読み込めます。このファイルに具体例などの自由記述や口調は含まれません。

具体例を紹介するときは「共有する文章の下書きを開く」から全文を確認・編集し、必要な文章だけ保存してください。自動送信はしません。

詳細JSON・HTML・スクリーンショットには本人の使い方や仕事の内容が含まれるため、他の人に渡す前に確認してください。`output/` 全体には会話の抜粋・評価・キャッシュがあるので、そのまま共有しないでください。不具合を報告する際も、生ログや結果ファイルを添付せず、エラー文の個人名やパスを伏せてください。
