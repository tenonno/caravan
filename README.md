# AI SINDAN

**同じAIでも、使い方は人それぞれ。会話履歴から、その違いを知るツールです。**

会話の一部を実行中のAIエージェントが文脈ごと読み、進め方やツールの使い方を38観点から観察します。4軸の要約と旅をテーマにした16タイプ、口調、気になった工夫をHTMLにまとめます。材料不足なら、無理にタイプを決めません。

使い方を聞き合うための試作です。能力・成果・人格の診断や、人のランキングには使いません。

## 試すには

必要なもの：**Python 3.10以降**と、ローカルファイルを読んでコマンドを実行できるAIコーディングエージェント。追加のPythonパッケージや、このツール用のAPIキーは不要です。エージェント側の利用枠・費用はかかります。

普段使っているローカルのAIエージェントに、**次の依頼文をそのまま渡してください。**

```text
https://github.com/tenonno/ai-sindan を使って、このPCのAIとの会話から診断してください。
作業場所に新しいフォルダとして取得し、skills/ai-sindan/SKILL.md に従ってください。
既存のフォルダを上書きせず、取得に必要なツールがなければ先に案内してください。
まず、読み取る履歴の範囲・利用するAIの処理先・注意事項を説明してください。
初回はlightで、診断自身の会話は除外してください。
私が内容を確認して承諾してから、抽出と読解を始めてください。
結果は output/semantic/index.html に出してください。
```

取得はエージェントに任せます（Gitがある環境ならcloneできます）。説明された範囲・処理先を確認して承諾すると、診断が始まります。完了後、取得先の `output/semantic/index.html` を開きます。スライドに貼る場合は画面内の **1画面サマリー** を使えます。

既に取得済みなら「このフォルダの `skills/ai-sindan/SKILL.md` を使って診断して」で始められます。Web版のチャットだけではPC内の履歴を取得できません。ローカルファイルを操作できるエージェントで実行してください。

スクリプト単独ではAIの診断は作れません。いま使っているエージェントが読解を担当します。自動で特定のモデルを呼び出したり、Bedrockへ切り替えたりする機能はありません。

## 履歴を読ませる前に

**ローカルの履歴でも、クラウド型エージェントに読ませると、その処理先に内容が渡ります。** 機密情報・個人情報・認証情報を含む可能性があります。職場の履歴は、所属先で認められた環境と範囲でのみ利用してください。自動マスクは完全ではありません。

注意文だけなら、履歴を読み取らずに確認できます。

```text
python skills/ai-sindan/scripts/semantic.py notice
```

## 読み取れる履歴と分析量

対応する保存形式は **Codex、Claude Code、Antigravity CLI** のローカル会話ログです。診断を実行するエージェントと、診断対象の履歴は別です。複数の対応履歴があれば、条件に合う各エージェントから抜粋を選びます。Antigravity IDE・旧Gemini CLIは対象外です。

| モード | 会話数の上限 | 会話本文＋実行情報の上限 |
|---|---:|---:|
| light（まず試す） | 6 | 12,000文字 |
| standard | 12 | 24,000文字 |
| deep | 24 | 48,000文字 |

初期設定は直近90日。すべての履歴をAIに読ませる方式ではありません。再実行では利用できる評価を再利用します。基準・指示・AIの出力や推論は上記の上限に含まれず、総トークン数や料金の上限ではありません。

現在はWindowsの開発環境で確認しています。ほかのOS・アプリ版・ログ形式での動作は保証していません。履歴が見つからない場合は、[詳しい使い方](docs/usage.md)の対応パスを確認してください。

## 結果を見せ合うには

- 比較用には、本人が内容を確認した `output/semantic/share-profile.json` を渡します。結果画面から最大3人分を読み込めます。
- スクリーンショットにも本人の使い方の情報が含まれます。公開する部分を選んでください。
- `output/` 全体を送らないでください。会話の抜粋・評価・キャッシュが入ります。HTMLにも観測理由や発見メモが含まれます。
- 不具合の報告に、生ログや結果ファイルをそのまま添付しないでください。エラー文からも個人名やパスを伏せてください。
