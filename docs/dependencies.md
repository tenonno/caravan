# 利用者に追加パッケージを入れない設計

2026-11-03にローカルの配布対象と実装を確認。

## 必要なもの

PC、既存のファイル操作可能なAIエージェント、Python 3.10以降（標準ライブラリのsqlite3を含む）、既存のブラウザー。対応形式のローカル履歴と、スキルのscripts・assets・LICENSEを含むフォルダ一式を使う。

スキル導入はファイルの配置。pip・uv・npm・npx、追加SDK、MCPサーバー、専用ブラウザーの導入は不要で、自動インストールもしない。前提が不足したら知らせて停止する。取得には既存エージェントのダウンロード機能等を使い、取得手段のための追加ソフトも入れない。

## 確認した境界

| 対象 | 確認結果 |
|---|---|
| `skills/caravan/scripts/*.py` | importはPython標準ライブラリまたは同梱モジュールのみ。パッケージ導入、外部コマンド起動、モデルAPI・HTTP通信の処理なし |
| HTMLテンプレート | JavaScript・CSSは内蔵。画像は同梱アセットからdata URI化。CDN・外部フォント・外部スクリプト・送信用APIの利用なし |
| 配布生成 | 標準ライブラリのみ。明示一覧で選別し、`dev/`・`presentations/`・`node_modules/`を拒否 |
| 開発専用 | `dev/browser`のPlaywrightやLT資料生成ランタイムには外部依存あり。診断には不要で配布から除外 |

## 再確認する方法と限界

`python -S -m unittest discover -s tests` で初回62件、抽出改善後の再確認では73件成功。`-S`はsite-packagesの自動読込を無効化する。配布・別フォルダ配置テストの子プロセスにも`-S`を指定し、架空の空履歴からHTML生成まで確認。importの標準ライブラリ／同梱モジュール検査も継続する。

この依存関係検査は架空データで実施し、実履歴をテスト入力にはしていない。許諾された履歴による抽出処理のパイロット確認は別に行い、私的データは配布しない（ADR 0018）。Python 3.10の全OSでの実機確認や、未知の脆弱性が存在しない証明ではない。HTMLの依存はソースを確認したもので、今回はブラウザー通信の動的計測は行っていない。外部エージェント自身の実装や、公開済みリポジトリの現状を保証する監査ではない。

追加依存の供給元を増やさない設計だが、スキル自体はコードを実行する。クラウド型AIに抜粋を読ませれば既存の処理先へ送られる。読取前の範囲・処理先・所属先規則の確認と承諾は引き続き必要。リスクゼロ、完全オフラインとは説明しない。

設計判断：[ADR 0017](adr/0017-no-user-packages.md)。
