# 0023: 4軸で全体像を示してから具体的な工夫へ進む

- 関連ADR: [0021](0021-grounded-use-cases.md)、[0022](0022-specific-choices-without-quota.md)の冒頭配置のみ置換

## 背景

具体的な工夫を優先した後、利用者から、全体像を理解しやすい4軸を最上部へ戻す要望があった。具体的な場面を知る目的と、最初に読み取る順序を分けて扱う。

## 決定と理由

PCの冒頭は左に旅人・タイプ、右に4軸を置く。その直後に選出済みの工夫と詳しい場面を続ける。ページ全体を1画面に押し込まず、具体例の説明全体や追加例を折りたたまない。見出しの重要度は保ち、標準の1280×720表示で4軸が見える間隔にする。文字拡大時や長文では縦スクロールを許容する。

選定基準、件数を埋めない方針、分類、分析日時、保存・共有の境界は変更しない。4軸が能力・性格や具体例の原因を示すとは扱わない。

## 比較対象

- 具体例を冒頭に置き続ける：全体像を先に見たいという要望に合わない。
- 4軸と具体例の全文を最初の画面に収める：文字の縮小や過剰な折りたたみを招くため採用しない。

## 影響・トレードオフ

全体像を把握しやすくなる一方、具体例を見るにはスクロールが必要になる。具体例を通常の文書として直後に置き、読める状態を保つ。再分析や移行処理は不要。

## 再検討する条件

タイプだけで読み終え、具体的な場面へ進めない場合や、4軸の見方が伝わらない場合。
