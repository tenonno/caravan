# 0029: 個人の発表資料はリポジトリ外で管理する

- 状態: Accepted
- 記録日・決定日: 2026-11-04
- 記録種別: 新規決定
- 実装状況: 実装済み
- 関連ADR: [0011](0011-public-distribution.md)

## 背景

配布物からの除外だけでは、開発リポジトリの履歴への私的資料の混入を防げない。

## 決定と理由

個人の発表資料、原稿、発表者ノート、スライド生成用ソースと書き出しファイルは、開発用を含むリポジトリの外で管理する。ローカルだけのコミットも禁止する。混入済みの資料は全参照と過去の履歴から除去する。公開用ZIPの除外規則は維持する。

## 比較対象

- 配布ZIPからだけ除外する：開発履歴に資料が残る。
- リポジトリ内のignoredフォルダで保管する：再混入の余地があるため、正式な保管先にはしない。

## 影響・トレードオフ

発表資料は製品ソースとは別に保管・更新する。製品に備わる汎用のサマリー表示や、その設計文書は引き続き製品ソースとして扱う。個別の発表内容や資料へのリンクを設計文書へ転記しない。

## 再検討する条件

製品として配布する説明資料が必要な場合は、私的資料と分けて公開範囲を明示する。
