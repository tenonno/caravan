# 0010: 固定レポート内に発表用の1画面サマリーを持つ

- 状態: Accepted
- 記録日・決定日: 2026-11-03
- 記録種別: 新規決定
- 実装状況: 実装済み。実ブラウザーの目視確認は未完了
- 関連ADR: [0007 固定レポート](0007-stable-standalone-reports.md)、[0008 旅の画像](0008-travel-names-and-art.md)

## 背景

LTの資料に結果のスクリーンショットを貼るため、タイプと進め方が一画面で分かる表示が必要になった。通常画面の根拠・発見メモ・口調まで詰めると、小さな文字や長いページになる。

## 決定と理由

`index.html` 内に通常表示と切り替える16:9のサマリーを設ける。タイプ名、共通イラスト、短い説明、判定状態、4軸、観測例を表示する。独立したHTMLや画像出力は追加しない。

観測例は評価済みかつ観測がある観点から定義順に最大3件、その名称だけを載せる。頻度や能力のランキングではない。会話の根拠、発見メモの自由記述、口調、正確な会話件数は転記しない。根拠は通常表示に残す。共有JSONの形式・項目も変更しない。

保留時は単独のイラストを選ばない。旧結果の4軸は未評価、材料不足の軸は位置マーカーなしで示す。中間・併用は片側に決めつけない。サマリーを作るための再診断・新しいAI要約は行わない。

広い画面ではウィンドウの幅と高さに合わせて比率を保って縮小する。幅700px以下では文字の読みやすさを優先して縦表示にする。ボタンとEscapeで通常表示へ戻れる。

## 比較対象

- 通常画面全体を縮小して撮影：操作部品や長文で文字が小さくなる。
- スライドごとに結果を書き直す：表示と保存結果が食い違いやすい。
- 別名HTMLを出力：最新の閲覧先が分散する。

## 影響・トレードオフ

発表では結果の要点を示しやすくなる一方、サマリーだけでは根拠と抽出範囲を詳しく読めない。抜粋の傾向であり優劣を測らない旨を画面内に残す。画面表示の切り替えであり、HTML自体を共有用に匿名化する機能ではない。

## 再検討する条件

PNGの保存機能が必要になる、1画面に載せる内容を利用者が選びたくなる、画面比率や可読性に問題が出る場合。
