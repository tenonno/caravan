# 0016: 公開リポジトリ名とスキル名をCaravanへ揃える

- 状態: Accepted
- 記録日・決定日: 2026-11-03
- 記録種別: 新規決定
- 実装状況: 公開リポジトリ・スキル・導入URL・配布名を更新
- 関連ADR: [0011](0011-public-distribution.md)、[0012](0012-installed-skill-workspace.md)、[0014](0014-caravan-brand.md)

## 背景

表示名をCaravanへ変更した後、リポジトリ名も揃える要望があった。まだ他者への配布前であり、呼び出し名も変更してよいとの指示を受けた。

## 決定と理由

既存の公開GitHubリポジトリを `ai-sindan` から `caravan` へ改名する。作り直しや履歴移行は行わない。READMEのスキル導入URLと公開用作業コピーのoriginを新しいURLへ更新する。0014のうちリポジトリURLとスキルIDを維持する判断を変更する。

診断スキルを `skills/caravan/` へ移し、SKILL.mdのnameも `caravan` にする。Codexは `$caravan`、Claude Codeは `/caravan` で呼び出す。配布ZIPを `caravan.zip`、展開先のルート名を `caravan/` とする。テスト・文書・画像制作手順の参照も更新する。ローカル作業フォルダと固定のHTML出力先は変えない。

## 比較対象

- 新しいリポジトリへ再公開：既存の履歴や参照を分断する。
- スキルIDを旧名に固定：配布前の段階で表示名と呼び出し名が不一致になる。
- ローカル作業フォルダまで移動：開いている固定レポートや作業場所を変える必要はない。

## 影響・トレードオフ

表示名・公開リポジトリ名・診断スキル名が揃う。試用中の旧スキルは自動で改名されないため、新しい名前で導入する。旧スキルの削除や他の環境の設定変更は自動では行わない。旧GitHub URLの転送を維持するため、元のリポジトリ名は別用途に再利用しない。既存利用者のローカル設定を勝手に書き換えない。

## 再検討する条件

追加の移行支援やプラグイン化を行う場合。

## 根拠・関連実装

リポジトリ名も更新したいという要望。[導入手順](../../README.md)、[GitHubの名称変更仕様](https://docs.github.com/en/repositories/creating-and-managing-repositories/renaming-a-repository)。
