# 0025: 日本語の推敲を表示と生成手順に組み込む

- 状態: Accepted
- 記録日・決定日: 2026-11-04
- 記録種別: 新規決定
- 実装状況: 実装済み
- 関連ADR: [0007](0007-stable-standalone-reports.md)、[0024](0024-result-reading-structure.md)

## 背景

利用者から、画面全体の日本語が抽象的でAI特有の文章に感じられるとの指摘があり、文案の試作後に全体改善を依頼された。旅の比喩や省略したラベルが、実際の使い方を理解する妨げになっていた。

## 決定と理由

旅人の名称・絵・配色を保ち、本文は具体的な依頼や選択を説明する日本語にする。固定文言を直すとともに、今後の診断文を作る手順に推敲の観点を加える。Impeccableのclarifyで画面文言を見直し、yomiyasuの意味保持と文章検査を開発時に利用する。診断実行時の追加依存にはしない。

既存の観察・判定・キャッシュ・分析日時・保存共有形式は変えない。4軸の表示名は既知のportrait-v1にだけ適用する。保存済みの個別の根拠文は自動置換しない。今回の変更は0024の配置判断を維持し、その後に認められた文章改善である。

## 比較対象

- 禁止語だけを置換する：主体や条件の曖昧さが残るため採用しない。
- 過去の観察を一括で書き換える：根拠との対応や確度を損なう可能性があり、表示の変更とは分ける。
- yomiyasuを診断の必須依存にする：利用者の追加導入が必要になるため採用しない。

## 影響・トレードオフ

本文は直接的になる一方、説明のために長くなるラベルもある。画面内で折り返しを確認する。既存の個別の根拠文には以前の文体が残る。

## 再検討する条件

観察文自体の推敲が必要になった場合、または文言変更が判定基準や保存互換性に影響する場合。
