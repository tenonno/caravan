# 0026: 復元した詳しい結果を単独HTMLで保存する

- 状態: Accepted
- 記録日・決定日: 2026-11-04
- 記録種別: 新規決定
- 実装状況: 実装済み
- 関連ADR: [0019](0019-private-result-backup.md)、[0007](0007-stable-standalone-reports.md)、[0004](0004-consent-and-private-data.md)

## 背景

他の利用者の結果を確認する用途から、詳しい画面の復元を求められた。既存の本人用JSONの読み込みは画面内に限られ、閉じた後の閲覧には再度読み込むかAIによる再生成が必要だった。保存操作も「比較・共有」の中に埋もれていた。

## 決定と理由

結果画面から「結果の保存・復元」を直接開けるようにする。詳細JSONの形式は変えず、旧版の本人用バックアップも引き続き読み込む。共有用JSONには根拠や具体例がないため、詳しい結果として読み込まない。

表示中の分析を、利用者の操作で単独HTMLとしてダウンロードできるようにする。初期描画前の組み込みテンプレートに選択中の分析データを埋め直し、会話由来の文字列はJSON内で安全に符号化する。画面内で編集した未保存の下書きや、比較相手のプロフィールは含めない。元のファイルを上書きせず、自動送信やブラウザーへの永続保存もしない。

ダウンロードしたHTMLから元の開発者ページへのリンクは取り除く。対応する別ファイルが存在せず、別の結果を誤って開く可能性があるため。結果画面と開発者画面の両方が必要な場合は、既存のCLI復元を使う。標準出力は引き続き固定の `output/semantic/index.html` と `developer.html` とする。

## 比較対象

- 共有用JSONから詳細を推測する：失われた根拠を復元できないため採用しない。
- 表示中のDOMをそのまま保存する：下書きや比較相手のデータが混ざるため採用しない。
- AIによる再生成だけにする：毎回の再生成なしに保存した画面を開きたい用途を満たさない。

## 影響・トレードオフ

HTMLは画像も含むためJSONより大きくなる。根拠文などの詳しい内容を含むため、渡す前の確認を画面で案内する。分析日時・分類・集計・共有用形式は変えない。相手の詳細を読むには、相手が選んで渡した詳細JSONが必要。

## 再検討する条件

HTML以外のファイルもブラウザーで一括保存する場合、自動同期や保存先指定を加える場合、詳細データの共有範囲を変える場合。
