# 0017: 利用者の環境に追加パッケージを導入しない

## 背景

利用時に依存パッケージの供給元・更新・実行権限の管理を増やしたくない。開発用依存を診断に必要なものと誤認させない。

## 決定と理由

診断・表示は既存AIエージェント、Python 3.10以降の標準ライブラリ、既存ブラウザー、同梱ファイルだけで行う。導入・更新・診断時の追加パッケージ、SDK、MCPサーバー、ブラウザー等のインストールを禁止し、不足があれば停止して報告する。開発・資料制作の依存は配布対象外を維持する。

## 比較対象

依存を自動導入する方式は、利用者の環境変更と供給元への信頼を増やすため採用しない。開発ツールの全廃は通常利用の境界とは別で、今回の対象にしない。

## 影響・トレードオフ

標準ライブラリで実装・検証できる範囲を維持する。前提ソフトがないPCでは停止する。追加依存がなくてもスキルのコード実行やクラウドAIでの処理に伴うリスクは残る。承諾手順は変えない。

## 再検討する条件

追加ライブラリが不可欠な機能を要求された場合。現方針のまま暗黙に導入せず、設計変更として判断する。
