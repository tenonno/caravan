# 0031: 制作用の元画像を診断スキルから分離する

- 状態: Accepted
- 記録日・決定日: 2026-11-04
- 記録種別: 新規決定
- 実装状況: 実装済み
- 関連ADR: [0008](0008-travel-names-and-art.md)、[0011](0011-public-distribution.md)

## 背景

診断画面はJPEGを使うが、同じ絵の制作元PNG16枚もスキルに入り、約38MBを占めていた。利用時には不要な制作素材によって配布容量が増えていた。

## 決定と理由

元PNGは開発用のdev/art/journeyへ移し、ローカルGitで保持する。診断スキルには配信用JPEG16枚と表示用ロゴを残す。元PNGは公開一覧と公開用ブランチの最新内容から除外する。画像の画素・表示・診断は変更しない。

制作スキルとJPEG書き出し処理は、元画像と配信用画像の場所を明示して別々に扱う。公開用ソースだけを持つ場合は元PNGがないことを明記し、制作時に開発用素材を別途用意する。

旧方式のreport.htmlと共有処理を持つdiagnose.pyは参照元があるため保持する。容量削減だけを目的に既存の互換機能を削除しない。

## 比較対象

- 配布一覧だけからPNGを除く：スキルフォルダごとのインストールには残る。
- 元PNGを削除する：再制作に必要な素材を失う。
- 全PNGを除く：結果に必要なロゴまで失う。

## 影響・トレードオフ

診断スキルは約39.3MBから約1.36MBになる。元画像は公開用ZIPにも含めない。過去の公開コミットには元画像が残るため、全履歴のclone容量が同じだけ減るわけではない。履歴の書き換えは行わない。

## 再検討する条件

表示解像度や配布方式を変更する場合、または制作元画像を別途配布する必要がある場合。
