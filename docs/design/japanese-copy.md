# Caravanの日本語

旅人の名前とイラストで旅の世界を表し、本文ではAIへの頼み方や実際の選択を説明する。文を短くすることより、誰が何をしたかが一度で読めることを優先する。

## 書き方

- 見出しは内容を直接示す。「相談の入口」より「何から相談するか」。
- 比喩の対象を明確にする。「行き先を伝えて道筋は任せる」より「目的を伝え、進め方はAIに任せる」。
- 「条件を置く」「選択が出る」など、読者が意味を補う表現を避ける。
- 人物の評価ではなく、確認できた依頼・選択・反応を書く。条件や理由が記録にない場合は補わない。
- 頼んだ、提案した、試した、完了した、完了したと報告した、を区別する。
- 不明、該当場面なし、今回見られなかった、まだ分析していない、を混同しない。
- 前置きや見出しの繰り返しは減らす。数値、条件、注意事項は短くするために落とさない。
- ボタンには操作後に何が起きるかを書く。下書きを開く操作を「文章を作る」と呼ばない。
